# Lode

**Lode** — минималистичный, быстрый десктопный Git-клиент для Windows, macOS и Linux на стеке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

---

## Что умеет (Этап 6: Конфликты)

1. **Парсинг маркеров конфликта (`src-tauri/src/git/conflict.rs`, `src/lib/conflictParser.ts`)**:
   - Чистый парсер 2-way маркеров (`<<<<<<<`, `=======`, `>>>>>>>`) и 3-way/diff3 маркеров (`|||||||` с общим предком base).
   - Сохранение исходных окончаний строк (CRLF / LF) и структуры файла.
   - Автоматическое выявление и разрешение блоков с идентичными изменениями (`ours == theirs`).
   - Функция валидации `contains_conflict_markers` / `hasConflictMarkers`: запрещает сохранение файла как решённого, пока в нём остаются неразрешённые маркеры.

2. **Трёхпанельный редактор и разрешение конфликтов (`src/features/conflicts/ConflictsView.tsx`)**:
   - Боковая панель списка конфликтных файлов со статусом `U`.
   - **Контекстные подписи сторон (Раздел 9.3 `CLAUDE.md`)**:
     - При `merge`: «Текущая ветка (`main`)» и «Вливаемая (`feature/xyz`)».
     - При `rebase`: смысл сторон инвертирован — «Основа (`upstream`)» и «Ваш коммит (`feature`)».
   - Навигация по блокам: счётчик «Блок X из Y», кнопки «Предыдущий», «Следующий».
   - Действия над блоком:
     - «Взять левое»;
     - «Взять правое»;
     - «Обе (левое, затем правое)»;
     - «Обе (правое, затем левое)».
   - Перегенерация конфликта в стиль `diff3` (`git checkout --conflict=diff3`) с диалогом-предупреждением о сбросе ручных правок.
   - Нижняя панель итогового результата: редактируемый текст с моноширинным шрифтом, подсветкой наличия маркеров и встроенной историей отмен (undo/redo).
   - Атомарная запись во временный файл с последующим переименованием и автоматическим добавлением в индекс (`git add -- <path>`).

3. **Обработка нетекстовых конфликтов (`DU`, `UD`, `AA`, `DD`, бинарные файлы)**:
   - Специальный интерфейс при отсутствии текстовых маркеров: выбор «Взять нашу версию», «Взять их версию», «Оставить файл» (`git add`) или «Удалить файл» (`git rm`).

4. **Панель «Все конфликты разрешены» и продолжение операции**:
   - Автоматическое появление поздравительной панели после решения всех файлов:
     - Поле редактирования итогового сообщения коммита;
     - Кнопка **«Продолжить»** (`--continue` с `GIT_EDITOR=true`, что исключает зависание git в ожидании текстового редактора);
     - Кнопка **«Отменить слияние»** (`--abort`).

5. **Remote и синхронизация (Этап 5)**:
   - Fetch (`--all --prune`), Pull (ff-only / merge / rebase), Push (`-u`, `--force-with-lease`).
   - Детекция `PushRejected` и безопасный force-push с подтверждением для веток `master`/`main`.
   - Маскирование паролей в URL и модальное окно управления remotes.

6. **Ветки, теги, merge и состояние репозитория (Этап 4)**:
   - Парсинг `git for-each-ref`, переключение, переименование, удаление веток и тегов.
   - Определение состояний `Merge`, `Rebase`, `CherryPick`, `Revert`, `Bisect` по файлам в `.git` через `git rev-parse --git-path`.

7. **История коммитов и граф веток (Этап 3)**:
   - Парсинг `git log -z`, чистый алгоритм lanes в `src/lib/graph.ts` (octopus-слияния, палитра из 8 цветов).
   - Виртуализированный рендеринг `@tanstack/react-virtual`, пагинация по 500 коммитов без разрывов линий.

8. **Индексация и коммиты (Этап 2)**:
   - Staging/unstaging/discard файлов, фрагментов (hunk) и строк по разделу 7.1.
   - Коммиты и amend через stdin (`-F -`), валидация темы до 72 символов.

9. **Статус, diff и файловый вотчер (Этап 1)**:
   - Porcelain v2 статус, режимы diff Inline / Side-by-side, вотчер с дебаунсом 200 мс.

## Требования к окружению

- **Git**: версия 2.30.0 или новее.
- **Node.js**: v18+ или v20+.
- **Rust**: stable toolchain (1.80+).
- **Платформенные зависимости**:
  - **Windows**: WebView2 (встроен в Windows 10/11).
  - **Linux (Ubuntu/Debian)**: `libwebkit2gtk-4.1-dev`, `build-essential`, `libssl-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`.
  - **macOS**: Xcode Command Line Tools.

## Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Запуск только веб-интерфейса (Vite)
```bash
npm run dev
```

## Проверка и тестирование

```bash
# Проверка типов TypeScript (строго без ошибок)
npm run typecheck

# Модульные тесты фронтенда (Vitest: граф, парсер конфликтов, сторы ui, status, refs, remote, conflict)
npm test

# Сборка веб-части
npm run build

# Все тесты Rust (парсеры, conflict markers, patch builder, интеграционные тесты Stage 1–6)
cargo test --manifest-path src-tauri/Cargo.toml

# Линтер Rust (строго без предупреждений)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```

## Известные ограничения (намеренно не сделано в Этапе 6)

- Stash, cherry-pick, revert, reset, blame — **Этап 7**.
- Интерактивный rebase с drag-and-drop списком и вспомогательным редактором — **Этап 8**.
- Палитра команд (Ctrl+K) и экран глобальных настроек — **Этап 9**.
