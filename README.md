# Lode

**Lode** — минималистичный, быстрый десктопный Git-клиент для Windows, macOS и Linux на стеке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

---

## Что умеет (Этап 1: Открытие репозитория, статус, diff)

1. **Архитектура запуска Git и безопасность (`src-tauri/src/git/runner.rs`)**:
   - Строгая изоляция: вызов только через массив аргументов с флагом `--` перед путями.
   - Изоляция окружения: `GIT_TERMINAL_PROMPT=0`, `GIT_PAGER=cat`, `LC_ALL=C`, `GIT_OPTIONAL_LOCKS=0` для всех операций чтения.
   - Потоковое чтение вывода в виде сырых байтов с обработкой невалидного UTF-8 через `String::from_utf8_lossy`.
   - На Windows запуск с `CREATE_NO_WINDOW` без мерцающих окон консоли.
   - Защита от гонок за `index.lock` с помощью очереди записи (`RepoQueue`) на уровне репозитория.

2. **Парсер статуса Porcelain v2 (`src-tauri/src/git/parse/status.rs`)**:
   - Парсинг `git status --porcelain=v2 -z --branch --untracked-files=normal`.
   - Поддержка заголовков веток (`# branch.head`, `# branch.upstream`, `# branch.ab +ahead -behind`, detached HEAD).
   - Чёткое разделение на списки «В индексе» (staged) и «Не в индексе» (unstaged).
   - Поддержка частично проиндексированных файлов (`MM` отображается одновременно в обоих списках).
   - Корректная обработка переименований/копий (двухзаписные NUL-сообщения формата `2 <XY> ... <path>\0<orig_path>\0`).
   - Обработка неотслеживаемых файлов (`?`) и конфликтов слияния (`u`).

3. **Парсер Unified Diff (`src-tauri/src/git/parse/diff.rs`)**:
   - Парсинг заголовков `diff --git`, `old mode`, `new mode`, `deleted file mode`, `new file mode`, `rename from/to`, `similarity index`.
   - Детекция переименований с флагом `-M`.
   - Поддержка бинарных файлов (`Binary files ... differ` или бинарный контент).
   - Сохранение и индикация окончаний строк CRLF (`\r\n`) на уровне каждой строки без обрезки и нормализации.
   - Поддержка маркера `\ No newline at end of file`.
   - Лимит на большие файлы: файлы более 5 000 строк или 1 МБ автоматически сворачиваются с кнопкой «Показать всё» для сохранения отзывчивости UI.

4. **Файловый вотчер (`src-tauri/src/watcher.rs`)**:
   - Фоновое наблюдение за `.git` (метаданные, `HEAD`, `index`, `refs`) и рабочим деревом через `notify`.
   - Игнорирование шумных директорий (`.git/objects`, `node_modules`, `target`, `.vite`, `.npm-cache`).
   - Дебаунс 200 мс для объединения пачек файловых событий в одно событие Tauri `repo:changed`.
   - Механизм подавления эхо-событий во время операций самого приложения.

5. **Пользовательский интерфейс «Изменения» (`src/features/changes/`)**:
   - Левая панель с изменяемой шириной:
     - Список «Не в индексе» с бейджем количества и цветовыми метками (`M`, `A`, `D`, `R`, `?`).
     - Список «В индексе» с бейджем количества.
     - Бейдж «частично» для файлов, изменённых и в индексе, и в рабочем дереве.
     - Поле ввода сообщения коммита с мягким ограничением темы (72 символа, счётчик окрашивается в красный при превышении).
     - Чекбокс «Изменить последний» (amend).
     - Кнопка «Закоммитить» (заблокирована до Этапа 2 с подсказкой).
   - Правая панель Diff:
     - Шапка с моноширинным путём, исходным путём при переименовании, счётчиками добавлений (`+X`) и удалений (`-Y`).
     - Переключатель режимов: **Inline** (построчный) и **Side-by-side** (двухколоночный сопоставительный).
     - Номера строк для старой и новой версии.
     - Специальные метки: `CRLF` для строк с возвратом каретки, `\ No newline` при отсутствии перевода строки.
     - Заглушка бинарных файлов с отображением размера файла.
   - Сайдбар с динамическими счётчиками изменений и индикатором опережения/отставания ветки (`↑1 ↓2`).

## Требования к окружению

- **Git**: версия 2.30.0 или новее.
- **Node.js**: v18+ или v20+.
- **Rust**: stable toolchain (1.80+).
- **Платформенные зависимости**:
  - **Windows**: WebView2 (встроен в Windows 10/11).
  - **Linux (Ubuntu/Debian)**: `libwebkit2gtk-4.1-dev`, `build-essential`, `libssl-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`.
  - **macOS**: Xcode Command Line Tools.

## Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Запуск только веб-интерфейса (Vite)
```bash
npm run dev
```

## Проверка и тестирование

```bash
# Проверка типов TypeScript
npm run typecheck

# Модульные тесты фронтенда (Vitest)
npm test

# Сборка веб-части
npm run build

# Все тесты Rust (парсеры, интеграционные тесты с реальным репозиторием, экспорт типов)
cargo test --manifest-path src-tauri/Cargo.toml

# Линтер Rust (строго без предупреждений)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```

## Известные ограничения (намеренно не сделано в Этапе 1)

- Staging/unstage файлов, отдельных hunk'ов и строк (`patch.rs`) — **Этап 2**.
- Создание коммитов и amend через `-F -` — **Этап 2**.
- Граф коммитов и виртуализированная история — **Этап 3**.
- Ветки, теги, checkout, merge и баннеры состояний — **Этап 4**.
- Remote-операции (fetch, pull, push) — **Этап 5**.
- Трёхпанельный редактор разрешения конфликтов — **Этап 6**.
