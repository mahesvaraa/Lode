# Lode

**Lode** — минималистичный, быстрый десктопный Git-клиент для Windows, macOS и Linux на стеке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

---

## Что умеет (Этап 2: Индекс и коммиты)

1. **Индексация файлов, фрагментов (hunk) и строк (`src-tauri/src/git/patch.rs`, `src-tauri/src/commands/staging.rs`)**:
   - Полная индексация / исключение файлов: `git add -A -- <path>` и `git restore --staged -- <path>` (с автоматическим откатом на `git rm --cached` в репозиториях без начального коммита).
   - Индексация / исключение всех файлов одним кликом (`stage_all` / `unstage_all`).
   - Построение патчей по разделу 7.1 `CLAUDE.md`:
     - Невыбранные `+` строки исключаются из патча.
     - Невыбранные `-` строки превращаются в контекстные строки (с ведущим пробелом).
     - Пересчёт диапазонов строк в заголовке `@@ -a,b +c,d @@` с передачей флага `--recount`.
     - Корректное сохранение маркеров `\ No newline at end of file` и окончаний строк `CRLF` без нормализации.
   - Построчный выбор изменений (клик по строкам с `+` и `-`) и индексация / исключение / откат выбранных строк.
   - Индексация / исключение целых фрагментов (hunk).
   - Поддержка новых файлов через автоматический `git add -N -- <path>` (intent-to-add).
   - Безопасный откат изменений (`discard_file`, `discard_lines`) с обязательным подтверждением через модальное окно.

2. **Создание и изменение коммитов (`src-tauri/src/commands/commit.rs`)**:
   - Передача сообщения коммита строго через stdin (`-F -`) для исключения проблем с кавычками, переносами строк, кириллицей и эмодзи.
   - Поддержка флага `--amend` («Изменить последний»).
   - Валидация сообщения коммита: мягкая подсказка первой строки (счётчик `N/72`, окрашивающийся в красный цвет при превышении 72 символов).
   - Горячая клавиша `Ctrl/Cmd+Enter` для отправки коммита.
   - Перехват и понятное отображение ошибок хуков (`pre-commit`, `commit-msg`) в баннере интерфейса.

3. **Архитектура запуска Git и безопасность (`src-tauri/src/git/runner.rs`)**:
   - Поддержка потокового ввода через `run_write_stdin` с мьютексом на репозиторий (`RepoQueue`).
   - Строгая изоляция: вызов только через массив аргументов с флагом `--` перед путями.
   - Изоляция окружения: `GIT_TERMINAL_PROMPT=0`, `GIT_PAGER=cat`, `LC_ALL=C`, `GIT_OPTIONAL_LOCKS=0` для всех операций чтения.
   - На Windows запуск с `CREATE_NO_WINDOW` без мерцающих окон консоли.

4. **Парсер статуса Porcelain v2 и Unified Diff (`src-tauri/src/git/parse/`)**:
   - Парсинг `git status --porcelain=v2 -z --branch --untracked-files=normal`.
   - Поддержка частично проиндексированных файлов (`MM`).
   - Детекция переименований с флагом `-M`.
   - Поддержка бинарных файлов и больших diff'ов (> 5 000 строк / > 1 МБ) с кнопкой «Показать всё».

5. **Файловый вотчер (`src-tauri/src/watcher.rs`)**:
   - Фоновое наблюдение за `.git` и рабочим деревом с дебаунсом 200 мс и фильтрацией шумных каталогов.

## Требования к окружению

- **Git**: версия 2.30.0 или новее.
- **Node.js**: v18+ или v20+.
- **Rust**: stable toolchain (1.80+).
- **Платформенные зависимости**:
  - **Windows**: WebView2 (встроен в Windows 10/11).
  - **Linux (Ubuntu/Debian)**: `libwebkit2gtk-4.1-dev`, `build-essential`, `libssl-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`.
  - **macOS**: Xcode Command Line Tools.

## Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Запуск только веб-интерфейса (Vite)
```bash
npm run dev
```

## Проверка и тестирование

```bash
# Проверка типов TypeScript (строго без ошибок)
npm run typecheck

# Модульные тесты фронтенда (Vitest)
npm test

# Сборка веб-части
npm run build

# Все тесты Rust (парсеры, построение патчей, интеграционные тесты Stage 1 и Stage 2)
cargo test --manifest-path src-tauri/Cargo.toml

# Линтер Rust (строго без предупреждений)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```

## Известные ограничения (намеренно не сделано в Этапе 2)

- Граф коммитов и виртуализированная история коммитов — **Этап 3**.
- Управление ветками, тегами, checkout, merge и баннеры состояний — **Этап 4**.
- Remote-операции (fetch, pull, push) — **Этап 5**.
- Трёхпанельный редактор разрешения конфликтов — **Этап 6**.
