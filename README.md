# Lode ⚡

**Lode** — легковесный, быстрый и безопасный десктопный Git-клиент для Windows, macOS и Linux.  
Построен на связке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

Приложение создано для тех, кто ценит максимальную производительность, строгую корректность операций с репозиторием и чистый интерфейс без лишнего визуального шума.

---

## Ключевые особенности

### ⚡ Производительность и отзывчивость
- **Никаких блокировок интерфейса**: все Git-операции выполняются асинхронно в Rust-бэкенде через пул Tokio.
- **Мгновенное открытие больших репозиториев**: репозитории на 100 000+ коммитов открываются менее чем за секунду благодаря пагинации и виртуализации списков (`@tanstack/react-virtual`).
- **Собственный файловый монитор**: отслеживание изменений через `notify` с дебаунсом 200 мс и автоматическим подавлением собственных дисковых событий.

### 🛡️ Безопасность и защита данных
- **Настоящий системный Git**: приложение вызывает локальный `git`, сохраняя все пользовательские настройки, SSH-ключи, GPG-подписи, хуки, `.gitattributes` и credential helpers.
- **Очередь операций**: команды записи (commit, checkout, merge, rebase, stash) выполняются строго последовательно через мьютекс, исключая гонки за `index.lock`.
- **Защита от потери данных**: деструктивные действия (`reset --hard`, удаление веток, откат файлов, force push) требуют явного подтверждения в диалоговом окне.
- **Безопасный Force Push**: только `--force-with-lease` и дополнительное подтверждение для защищённых веток (`main`, `master`).
- **Подсказки отмены через Reflog**: при сбросе ветки (`git reset --hard`) в интерфейсе появляется уведомление с кнопкой быстрой отмены через `git reset --hard ORIG_HEAD`.

### 🧭 Понятные конфликты (3-Way Merge)
- **Трёхпанельный редактор**: левая версия, правая версия и итоговый результат в центре с подсветкой синтаксиса и поддержкой Undo/Redo.
- **Честные подписи сторон**: при `rebase` и `cherry-pick` роли автоматически корректируются («Основа» и «Ваш коммит»), исключая путаницу `ours/theirs`.
- **Поддержка форматов diff3**: корректный парсинг маркеров `<<<<<<<`, `=======`, `>>>>>>>` и базовой версии `|||||||`.
- **Защита от случайных маркеров**: файл невозможно пометить решённым, пока в нём остаётся хотя бы один конфликтный маркер.

### 🖱️ Контекстные меню и Status Bar
- **Нативные контекстные меню по ПКМ**: полное отсутствие браузерного меню Chromium/WebKit. Для любого объекта (коммит, локальная/удалённая ветка, файл, фрагмент diff, строка blame) доступно контекстное меню.
- **Подменю второго уровня**: адаптивное оверлейное позиционирование с защитой от случайного закрытия (150 мс) и навигацией со стрелок клавиатуры.
- **Живая строка состояния (Status Bar)**: при наведении на любой пункт меню или кнопку внизу экрана отображается точная команда Git (`⚡ Команда: git reset --hard 7be02d4`), которая будет вызвана.
- **Специализированное меню для полей ввода**: полнофункциональное меню редактирования текста (Отменить, Повторить, Вырезать, Копировать, Вставить, Выделить всё).

### 🔍 История, граф и быстрый поиск
- **Интерактивный граф веток**: чистый алгоритм lanes с 8 различимыми и безопасными для дальтоников цветами, поддержка octopus-слияний.
- **Умный поиск коммитов**:
  - по тексту сообщения коммита (регистронезависимо);
  - по имени или email автора;
  - по имени или email коммитера;
  - по частичному (от 4 символов) или полному хешу SHA.
- **Инфо о коммите**: статистика добавленных и удалённых строк (`+X −Y`) по каждому файлу и суммарно по всему коммиту, быстрый переход к родителям.

### ✂️ Гибкая индексация и Diff
- **Пофайловый, пофрагментный и построчный staging**: добавление и исключение отдельных строк или hunk'ов через stdin-патчи с сохранением окончаний строк (CRLF/LF).
- **Симметричный Side-by-side diff**: строгое деление экрана 50% / 50% с синхронной вертикальной и горизонтальной прокруткой обеих половин.
- **Inline diff**: компактный построчный просмотр изменений.
- **Лимиты производительности**: автоматическое сворачивание гигантских diff'ов (> 5 000 строк или > 1 МБ) с кнопкой «Показать всё».

### 🔀 Интерактивный Rebase (`rebase -i`)
- Визуальный редактор цепочки коммитов: переупорядочивание (`▲ / ▼`), действия `pick`, `reword` (с диалогом редактирования сообщения), `squash`, `fixup`, `drop`.
- Работает через встроенный бинарный хелпер (`rebase_helper`) без нестабильных shell-скриптов.

## Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl+K` / `Cmd+K` | Открыть палитру команд |
| `Ctrl+1` | Перейти во вкладку **История** |
| `Ctrl+2` | Перейти во вкладку **Изменения** |
| `Ctrl+3` | Перейти во вкладку **Конфликты** |
| `Ctrl+O` | Открыть локальный репозиторий |
| `Ctrl+,` | Открыть **Настройки** |
| `Ctrl+Enter` | Создать коммит |
| `Ctrl+Shift+A` | Добавить все изменённые файлы в индекс |
| `F5` | Обновить состояние репозитория вручную |
| `Shift+F10` / `Menu` | Открыть контекстное меню для выбранного элемента |
| `▲` / `▼` | Навигация по спискам и пунктам меню |
| `◄` / `►` | Открытие и закрытие вложенных подменю |
| `Esc` | Закрыть меню, модальное окно или палитру |

## Стек технологий

| Компонент | Технология | Описание |
|---|---|---|

## Системные требования

- **Операционная система**:
  - Windows 10 / 11 (требуется WebView2, встроен в систему).
  - macOS 11+ (Big Sur и новее).
  - Linux (Ubuntu 20.04+, Fedora, Arch и др. с WebKitGTK 4.1).
- **Git**: версия **2.30.0** или выше.
- **Для сборки из исходников**:
  - Node.js 18.x или 20.x
  - Rust stable 1.80+ (`rustup default stable`)

## Запуск из исходников

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-username/lode.git
cd lode

# 2. Установка зависимостей фронтенда
npm install

# 3. Запуск в режиме разработки (Tauri + Vite dev server)
npm run tauri dev
```

## Тестирование и качество кода

Проект содержит всесторонний набор тестов для всех ключевых компонентов:

```bash
# 1. Проверка типов TypeScript (без единой ошибки)
npm run typecheck

# 2. Модульные тесты фронтенда (Vitest: граф, меню, валидация веток, парсер конфликтов)
npm test

# 3. Проверка тестов Rust (парсеры porcelain v2, diff, stash, numstat, интеграционные тесты)
cargo test --manifest-path src-tauri/Cargo.toml

# 4. Проверка линтером Rust (строгий режим -D warnings)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings

# 5. Сборка продакшен-бандла фронтенда
npm run build
```

## Сборка релизных пакетов

Сборка готовых установочных дистрибутивов для текущей платформы:

```bash
npm run tauri build
```

Итоговые файлы будут сгенерированы в каталоге `src-tauri/target/release/bundle/`:
- **Windows**: `.msi` и `.exe` (NSIS-установщик).
- **macOS**: `.dmg` и `.app` (Universal Binary для Intel и Apple Silicon).
- **Linux**: `.AppImage` и `.deb`.
