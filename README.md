# Lode

**Lode** — минималистичный, быстрый десктопный Git-клиент для Windows, macOS и Linux на стеке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

---

## Что умеет (Этап 3: История и граф)

1. **История коммитов и граф веток (`src-tauri/src/git/parse/log.rs`, `src/lib/graph.ts`)**:
   - Парсинг `git log -z --date-order --format=...` с разделителями `%x1f` между полями и NUL между коммитами.
   - Чистая функция построения графа в `src/lib/graph.ts` (раздел 6.3 `CLAUDE.md`):
     - Отслеживание активных колонок `lanes[]` с сохранением состояния между страницами пагинации без разрывов линий.
     - Корректная обработка merge-коммитов с двумя родителями и **octopus-слияний** с 3+ родителями.
     - Обработка root-коммитов, пустых и многострочных описаний, кириллицы и эмодзи.
     - Палитра из 8 приглушённых оттенков, различимых в обеих темах и безопасных для дальтоников.
   - Виртуализированный рендеринг списка коммитов на `@tanstack/react-virtual` с фиксированной высотой строки 34 px и плавной прокруткой 60 fps.
   - Бесшовная пагинация (подгрузка по 500 коммитов) при приближении к концу списка.

2. **Поиск и фильтрация истории**:
   - Поиск с дебаунсом по сообщению коммита, автору или хешу.
   - Выпадающий фильтр по веткам (`--all` для всех веток или `HEAD` для текущей ветки).

3. **Панель деталей коммита (`src/features/history/CommitDetailsPanel.tsx`)**:
   - Полный хеш, тема коммита, многострочное тело, автор и коммитер с датами.
   - Кликабельные ссылки на родительские коммиты для быстрого перехода в истории.
   - Чипы ссылок (акцентный `HEAD`, ветки, теги 🏷).
   - Список затронутых файлов с цветовыми бейджами статусов (`M`, `A`, `D`, `R`) и информацией об исходном пути при переименовании.
   - Просмотр Unified Diff для любого выбранного файла из коммита с подсветкой добавлений/удалений и номеров строк.

4. **Индексация и коммиты (Этап 2)**:
   - Полная и частичная индексация: файлы, фрагменты (hunk), строки.
   - Построение патчей по разделу 7.1 `CLAUDE.md` с сохранением CRLF и `\ No newline`.
   - Коммиты и amend через stdin (`-F -`), валидация темы (мягкий лимит 72 символа).
   - Подтверждение опасных операций (discard) через модальные окна.

5. **Статус, diff и файловый вотчер (Этап 1)**:
   - Porcelain v2 статус, детекция переименований с `-M`.
   - Режимы diff (Inline и Side-by-side).
   - Дебаунс файлового вотчера 200 мс и подавление эхо-событий.

## Требования к окружению

- **Git**: версия 2.30.0 или новее.
- **Node.js**: v18+ или v20+.
- **Rust**: stable toolchain (1.80+).
- **Платформенные зависимости**:
  - **Windows**: WebView2 (встроен в Windows 10/11).
  - **Linux (Ubuntu/Debian)**: `libwebkit2gtk-4.1-dev`, `build-essential`, `libssl-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`.
  - **macOS**: Xcode Command Line Tools.

## Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Запуск только веб-интерфейса (Vite)
```bash
npm run dev
```

## Проверка и тестирование

```bash
# Проверка типов TypeScript (строго без ошибок)
npm run typecheck

# Модульные тесты фронтенда (Vitest: граф, сторы)
npm test

# Сборка веб-части
npm run build

# Все тесты Rust (парсеры, построение патчей, интеграционные тесты Stage 1, Stage 2 и Stage 3)
cargo test --manifest-path src-tauri/Cargo.toml

# Линтер Rust (строго без предупреждений)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```

## Известные ограничения (намеренно не сделано в Этапе 3)

- Управление ветками, тегами, checkout, merge и баннеры состояний — **Этап 4**.
- Remote-операции (fetch, pull, push) — **Этап 5**.
- Трёхпанельный редактор разрешения конфликтов — **Этап 6**.
