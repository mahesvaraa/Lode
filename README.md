# Lode

**Lode** — минималистичный, быстрый десктопный Git-клиент для Windows, macOS и Linux на стеке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

---

## Что умеет (Этап 8: Интерактивный rebase)

1. **Вспомогательный бинарник-редактор (`src-tauri/src/bin/rebase_helper.rs`, `src-tauri/src/git/rebase.rs`)**:
   - Автономный исполняемый модуль без графического интерфейса, запускаемый git через `GIT_SEQUENCE_EDITOR` и `GIT_EDITOR`.
   - Заменяет необходимость в ненадежных shell-скриптах на Windows и Linux.
   - Корректно экранирует пути к исполняемым файлам с пробелами.
   - Подменяет список `git-rebase-todo` сформированной в UI последовательностью действий.
   - При действии `reword` автоматически подставляет отредактированное в приложении сообщение коммита в файл `COMMIT_EDITMSG`.

2. **Интерфейс интерактивного rebase (`src/features/rebase/InteractiveRebaseModal.tsx`)**:
   - Открытие rebase от родителя любого выбранного коммита в истории по кнопке «Rebase -i...».
   - Переупорядочивание коммитов с помощью кнопок «▲ / ▼» (drag-and-drop / клавиатурная навигация).
   - Выпадающий список действий для каждого коммита:
     - `pick` — применить коммит как есть;
     - `reword` — изменить сообщение коммита (открывает окно редактирования сообщения);
     - `squash` — слить коммит с предыдущим и объединить их сообщения;
     - `fixup` — слить коммит с предыдущим, выбросив сообщение;
     - `drop` — исключить коммит из цепочки.
   - Валидация: первый коммит цепочки автоматически защищён от `squash` / `fixup`.
   - **Предупреждение о безопасности (Раздел 10 и 11 `CLAUDE.md`)**:
     - Проверка коммитов через `git rev-list --remotes`.
     - При попытке переписать уже опубликованные коммиты выводится предупреждающий баннер: *«Внимание: цепочка содержит опубликованные на remote коммиты. Переписывание истории изменит их хеши и потребует git push --force-with-lease»*.
   - Панель предпросмотра итоговой цепочки (количество результирующих коммитов, число объединённых и удалённых).
   - При возникновении конфликта в процессе rebase git корректно останавливается, детекция состояния переводит приложение в трёхпанельный редактор конфликтов (`ConflictsView`) с индикатором шага («Шаг X из Y»).

3. **Stash, Cherry-pick, Revert, Reset, Blame (Этап 7)**:
   - Stash (`push -u`, apply, pop с переходом в конфликты, drop с подтверждением).
   - Cherry-pick с выбором родителя `-m 1/2`, Revert (`--no-edit`).
   - Reset (soft / mixed / hard с подтверждением и toast-кнопкой отмены через `ORIG_HEAD`).
   - Blame (`git blame --porcelain`) и история файла с отслеживанием переименований (`--follow`).

4. **Конфликты (Этап 6)**:
   - 2-way и diff3 парсер, трёхпанельный редактор с инверсией сторон (ours/theirs) при rebase/cherry-pick, валидация маркеров, атомарная запись.

5. **Remote и синхронизация (Этап 5)**:
   - Fetch, Pull (ff-only / merge / rebase), Push (`--force-with-lease`), детекция PushRejected, маскирование URL.

6. **Ветки, теги, merge и состояние репозитория (Этап 4)**:
   - Парсинг `git for-each-ref`, переключение, ветки, теги, верхний `StateBanner`.

7. **История коммитов и граф веток (Этап 3)**:
   - Виртуализированный рендеринг `@tanstack/react-virtual`, алгоритм lanes (8 цветов, octopus-слияния).

8. **Индексация и коммиты (Этап 2)**:
   - Построчный и пофрагментный staging, discard с подтверждением, commit через stdin (`-F -`).

9. **Статус, diff и файловый вотчер (Этап 1)**:
   - Porcelain v2 статус, Inline / Side-by-side diff, вотчер с дебаунсом 200 мс.

## Требования к окружению

- **Git**: версия 2.30.0 или новее.
- **Node.js**: v18+ или v20+.
- **Rust**: stable toolchain (1.80+).
- **Платформенные зависимости**:
  - **Windows**: WebView2 (встроен в Windows 10/11).
  - **Linux (Ubuntu/Debian)**: `libwebkit2gtk-4.1-dev`, `build-essential`, `libssl-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`.
  - **macOS**: Xcode Command Line Tools.

## Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Запуск только веб-интерфейса (Vite)
```bash
npm run dev
```

## Проверка и тестирование

```bash
# Проверка типов TypeScript (строго без ошибок)
npm run typecheck

# Модульные тесты фронтенда (Vitest: граф, парсер конфликтов, сторы ui, status, refs, remote, conflict, stash)
npm test

# Сборка веб-части
npm run build

# Все тесты Rust (парсеры, conflict markers, stash, blame, rebase, интеграционные тесты Stage 1–8)
cargo test --manifest-path src-tauri/Cargo.toml

# Линтер Rust (строго без предупреждений)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```
