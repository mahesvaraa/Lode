# Lode

**Lode** — минималистичный, быстрый десктопный Git-клиент для Windows, macOS и Linux на стеке **Tauri 2 + Rust + React 18 + TypeScript + Vite**.

---

## Что умеет (Этап 7: Stash, cherry-pick, revert, reset, blame)

1. **Управление Stash (`src-tauri/src/git/parse/stash.rs`, `src/features/stash/StashModal.tsx`)**:
   - Создание отложенных изменений с флагом `-u` (`--include-untracked`) и пользовательским описанием.
   - Парсинг списка `git stash list` в чистую структуру `StashItem` (индекс, селектор `stash@{n}`, дата, сообщение, хеш).
   - Просмотр unified diff содержимого стэша (`git stash show -p stash@{n}`).
   - Применение (`apply`) и извлечение (`pop`).
   - **Приёмочный критерий**: при возникновении конфликта во время `git stash pop` стэш сохраняется в списке, а приложение автоматически переключается в трёхпанельный редактор конфликтов из Этапа 6.
   - Удаление стэша (`drop`) через обязательное модальное окно подтверждения по разделу 11 `CLAUDE.md`.

2. **Cherry-pick и Revert (`src-tauri/src/commands/ops.rs`, `src/features/history/CommitDetailsPanel.tsx`)**:
   - Перенос любого коммита в текущую ветку по кнопке «Cherry-pick».
   - Для merge-коммитов с несколькими родителями — диалог выбора номера родителя (`-m 1`, `-m 2`).
   - Отмена изменений выбранного коммита с созданием нового коммита по кнопке «Revert» (`git revert --no-edit`).
   - При конфликтах в ходе cherry-pick или revert — детекция состояний `CHERRY_PICK_HEAD` / `REVERT_HEAD`, показ баннера состояния и переход в редактор конфликтов.

3. **Сброс веток (Reset) и безопасность данных (Раздел 11 `CLAUDE.md`)**:
   - Диалог сброса указателя ветки на любой коммит с выбором одного из трёх режимов:
     - **Soft (`--soft`)**: перемещает указатель, изменения остаются staged в индексе;
     - **Mixed (`--mixed`)**: режим по умолчанию, изменения остаются в рабочей копии как unstaged;
     - **Hard (`--hard`)**: опасная операция с предупреждением о потере незакоммиченных данных.
   - **Интерактивная подсказка восстановления**: после выполнения `hard reset` в toast-уведомлении выводится команда `git reset --hard ORIG_HEAD` и активная кнопка «Отменить», позволяющая в один клик вернуть ветку в исходное состояние.

4. **Инспекция файлов: Blame и История с отслеживанием переименований (`BlameModal.tsx`)**:
   - Парсер `git blame --porcelain` (`src-tauri/src/git/parse/blame.rs`): построчный просмотр файла с номерами строк, кратким хешем коммита, именем автора, датой, описанием коммита и кодом.
   - Вкладка «История файла (`git log --follow`)»: отображение коммитов, изменивших файл, с сохранением цепочки истории даже после переименования файла.

5. **Конфликты (Этап 6)**:
   - 2-way и diff3 парсер, трёхпанельный редактор с инверсией сторон (ours/theirs) при rebase/cherry-pick, валидация маркеров, атомарная запись.

6. **Remote и синхронизация (Этап 5)**:
   - Fetch, Pull (ff-only / merge / rebase), Push (`--force-with-lease`), детекция PushRejected, маскирование URL.

7. **Ветки, теги, merge и состояние репозитория (Этап 4)**:
   - Парсинг `git for-each-ref`, переключение, ветки, теги, верхний `StateBanner`.

8. **История коммитов и граф веток (Этап 3)**:
   - Виртуализированный рендеринг `@tanstack/react-virtual`, алгоритм lanes (8 цветов, octopus-слияния).

9. **Индексация и коммиты (Этап 2)**:
   - Построчный и пофрагментный staging, discard с подтверждением, commit через stdin (`-F -`).

10. **Статус, diff и файловый вотчер (Этап 1)**:
    - Porcelain v2 статус, Inline / Side-by-side diff, вотчер с дебаунсом 200 мс.

## Требования к окружению

- **Git**: версия 2.30.0 или новее.
- **Node.js**: v18+ или v20+.
- **Rust**: stable toolchain (1.80+).
- **Платформенные зависимости**:
  - **Windows**: WebView2 (встроен в Windows 10/11).
  - **Linux (Ubuntu/Debian)**: `libwebkit2gtk-4.1-dev`, `build-essential`, `libssl-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`.
  - **macOS**: Xcode Command Line Tools.

## Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 3. Запуск только веб-интерфейса (Vite)
```bash
npm run dev
```

## Проверка и тестирование

```bash
# Проверка типов TypeScript (строго без ошибок)
npm run typecheck

# Модульные тесты фронтенда (Vitest: граф, парсер конфликтов, сторы ui, status, refs, remote, conflict, stash)
npm test

# Сборка веб-части
npm run build

# Все тесты Rust (парсеры, conflict markers, stash, blame, интеграционные тесты Stage 1–7)
cargo test --manifest-path src-tauri/Cargo.toml

# Линтер Rust (строго без предупреждений)
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```
